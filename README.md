# Rocket Engine Tool

 The RocketEnigneTool is a program that use rocket formulas to make some simulations of how a rocket engine works. It is supposed to be in two parts to show the difference between the theory and the practics.

 
# What can it do
 Its purposes are to do in the first place the theorical calculation of an engine of a rocket throught a series of formulas and graphics, helping understanding how an engn works. In second place I want to build a hardware part that can take some data from its sensors and create a csv file which I can upload to the first part and it can tell the difference between the experimental and the theorycal calculus.
